PDF Toolkit 사용 설명서

올인원 PDF 도구 — 병합 · 분할 · 워터마크 · 프린트용 변환

오프라인(Standalone) · 인터넷 연결 불필요 · 브라우저 단독 실행
실행 방법: index.html 파일을 웹 브라우저(Chrome, Edge 등)로 열어주세요. 모든 처리는 사용자 PC 내에서 이루어지며, 파일이 서버로 전송되지 않습니다.

1PDF 병합

여러 PDF 및 이미지 파일을 하나의 PDF로 합칩니다.

  • 파일 추가: 파일을 드래그하거나 파일 선택 클릭 (PDF, JPG, PNG, BMP, GIF, TIFF, WebP 지원)
  • 추가 파일: 파일이 이미 로드된 상태에서도 화면 위에 파일을 드래그하면 바로 추가 가능. + 버튼도 사용 가능
  • 파일 순서 변경:
    • 상단 파일 목록에서 다중 선택 후 드래그 앤 드롭
    • 선택: 클릭 단일 / Ctrl+클릭 추가 / Shift+클릭 범위
  • 이름순 정렬: 헤더의 ↑ A→Z / ↓ Z→A 버튼으로 파일명 오름·내림차순 정렬
  • 페이지 순서 변경: 하단 미리보기에서 다중 선택 → 드래그로 페이지 단위 재배치
  • 페이지 회전: 개별 또는 전체 90° 회전
  • 북마크(목차):
    • 자동 생성: 파일명 기준 자동 목차 생성
    • 수동 추가: 제목·페이지·계층 구조 편집 가능
  • 결과 저장: PDF 병합 및 다운로드 클릭

2PDF 분할

PDF에서 원하는 페이지를 선별 추출하거나 개별 분할합니다.

  • 파일 추가: 분할할 PDF 파일 1개를 업로드
  • 페이지 선택: 미리보기에서 추출할 페이지를 클릭하여 선택 (전체 선택 지원)
  • 페이지 회전: 선택 페이지만 90°씩 회전 가능 (회전 상태가 추출 결과에 반영됨)
  • 추출 방법 2가지:
    • 하나의 PDF로 추출: 선택한 페이지들을 1개의 PDF로 합쳐서 저장
    • 개별 분할 다운로드: 선택한 페이지를 각각 개별 파일로 분할 (ZIP 다운로드)
  • 출력 형식:
    형식설명
    PDF페이지별 PDF 파일 (또는 합본 PDF)
    PNG고해상도 이미지 (1x/2x/3x DPI 선택)
    JPEG고해상도 이미지 (1x/2x/3x DPI 선택)
  • 파일 이름: 분할 파일명에 4자리 일련번호 부여 (_page0001, _page0002 …) — 파일 정렬 용이

3워터마크 삽입

PDF 위에 로고·도장·텍스트 이미지를 투명하게 겹쳐 삽입합니다.

  • 원문 PDF: 워터마크를 입힐 바탕 PDF 파일 업로드
  • 워터마크 파일: 겹쳐 올릴 파일 업로드 (PDF, JPG, PNG)
  • 배치 위치:
    • 중앙, 좌상단, 우상단, 좌하단, 우하단
    • 대각선 반복: 격자 패턴으로 워터마크 타일 배치
  • 불투명도: 슬라이더로 0~100% 조절
  • 크기: 슬라이더로 10~200% 조절
  • 여백: 가장자리 배치 시 여백(mm) 조절 가능
  • 미리보기: 미리보기 생성 버튼으로 적용 결과 확인 (Multiply 블렌딩으로 원본 글씨 가려지지 않음)
  • 결과 저장: 워터마크 삽입 후 다운로드 클릭

4프린트용 변환

긴 스크린샷 이미지를 A4 용지 폭에 맞게 확대하여 다중 페이지 PDF로 변환합니다.

  • 이미지 추가: 긴 스크린샷(PNG, JPG 등) 파일을 드래그 또는 선택
  • 용지 설정:
    옵션설명
    용지 크기A4 / Letter / Legal
    용지 방향세로(Portrait) / 가로(Landscape)
    여백0~30mm 슬라이더 조절
    페이지 겹침0~50mm — 이전 페이지 끝부분을 다음 페이지에 중복 표시하여 내용 연결 보장
  • 실시간 미리보기: 옵션 변경 시 페이지 분할 결과가 즉시 업데이트됨
  • 비율 유지: 마지막 페이지에 남은 이미지가 적을 경우 용지에 늘리지 않고 원본 비율 그대로 출력
  • 결과 저장: N페이지 PDF 다운로드 클릭
휴대전화 긴 캡처(스크롤 캡처)를 A4 용지에 맞춰 인쇄하고 싶을 때 유용합니다.
