PDF Toolkit 사용 설명서

올인원 PDF 도구 — HWP/HWPX 변환 · 병합 · 분할 · 워터마크 · 프린트용 변환

오프라인(Standalone) · 인터넷 연결 불필요 · 무음 백그라운드 단독 실행
🚀 실행 방법: 폴더 내의 PDF_Toolkit_실행.bat 또는 PDF Toolkit v4 (아이콘 실행).lnk를 더블클릭해주세요! 검은 도스(Terminal) 창 없이 무음 숨김 모드로 웹앱이 시작됩니다. (일반 index.html을 먼저 열고 나중에 실행해도 2초 내로 서버 가동을 인식하여 쾌속 스마트 이동)
※ 모든 연산을 사용자 로컬 PC 내부에서 수행하며 외부 인터넷 서버로 문서가 절대 전송되지 않는 100% 독립형 오프라인 보장 시스템입니다.

1PDF 병합

여러 PDF 및 이미지 파일을 하나의 PDF로 합칩니다.

  • 파일 추가: 파일을 드래그하거나 파일 선택 클릭 (PDF, JPG, PNG, BMP, GIF, TIFF, WebP 지원)
  • 추가 파일: 파일이 이미 로드된 상태에서도 화면 위에 파일을 드래그하면 바로 추가 가능. + 버튼도 사용 가능
  • 파일 순서 변경:
    • 상단 파일 목록에서 다중 선택 후 드래그 앤 드롭
    • 선택: 클릭 단일 / Ctrl+클릭 추가 / Shift+클릭 범위
  • 이름순 정렬: 헤더의 ↑ A→Z / ↓ Z→A 버튼으로 파일명 오름·내림차순 정렬
  • 페이지 순서 변경: 하단 미리보기에서 다중 선택 → 드래그로 페이지 단위 재배치
  • 회전된 페이지 자동 인식: PDF 내에 이미 회전 처리된 페이지(가로 등)는 원본 방향 그대로 표시됨
  • 페이지 회전:
    • 개별 회전: 페이지에 마우스를 올리면 나타나는 회전 버튼 클릭
    • 선택된 페이지 회전: Ctrl+클릭으로 여러 페이지를 다중 선택한 뒤 선택된 페이지 회전 버튼 클릭 → 선택된 페이지들만 일괄 90° 회전
    • 전체 회전: 전체 90° 회전 버튼으로 모든 페이지 한꺼번에 회전
  • 북마크(목차):
    • 자동 생성: 파일명 기준 자동 목차 생성
    • 수동 추가: 제목·페이지·계층 구조 편집 가능
  • 결과 저장: PDF 병합 및 다운로드 클릭

2PDF 분할

PDF에서 원하는 페이지를 선별 추출하거나 개별 분할합니다.

  • 파일 추가: 분할할 PDF 파일 1개를 업로드
  • 페이지 선택: 미리보기에서 추출할 페이지를 클릭하여 선택 (전체 선택 지원)
  • 회전된 페이지 자동 인식: PDF 내에 이미 회전 처리된 페이지(가로 등)는 원본 방향 그대로 표시됨
  • 페이지 회전: 선택 페이지만 90°씩 회전 가능 (회전 상태가 추출 결과에 반영됨)
  • 추출 방법 2가지:
    • 하나의 PDF로 추출: 선택한 페이지들을 1개의 PDF로 합쳐서 저장
    • 개별 분할 다운로드: 선택한 페이지를 각각 개별 파일로 분할 (ZIP 다운로드)
  • 출력 형식:
    형식설명
    PDF페이지별 PDF 파일 (또는 합본 PDF)
    PNG고해상도 이미지 (1x/2x/3x DPI 선택)
    JPEG고해상도 이미지 (1x/2x/3x DPI 선택)
  • 파일 이름: 분할 파일명에 4자리 일련번호 부여 (_page0001, _page0002 …) — 파일 정렬 용이

3워터마크 삽입

PDF 위에 로고·도장·텍스트 이미지를 투명하게 겹쳐 삽입합니다.

  • 원문 PDF: 워터마크를 입힐 바탕 PDF 파일 업로드
  • 워터마크 파일: 겹쳐 올릴 파일 업로드 (PDF, JPG, PNG)
  • 배치 위치:
    • 중앙, 좌상단, 우상단, 좌하단, 우하단
    • 대각선 반복: 격자 패턴으로 워터마크 타일 배치
  • 불투명도: 슬라이더로 0~100% 조절
  • 크기: 슬라이더로 10~200% 조절
  • 여백: 가장자리 배치 시 여백(mm) 조절 가능
  • 미리보기: 미리보기 생성 버튼으로 적용 결과 확인 (Multiply 블렌딩으로 원본 글씨 가려지지 않음)
  • 결과 저장: 워터마크 삽입 후 다운로드 클릭

4프린트용 변환

긴 스크린샷 이미지를 A4 용지 폭에 맞게 확대하여 다중 페이지 PDF로 변환합니다.

  • 이미지 추가: 긴 스크린샷(PNG, JPG 등) 파일을 드래그 또는 선택
  • 용지 설정:
    옵션설명
    용지 크기A4 / Letter / Legal
    용지 방향세로(Portrait) / 가로(Landscape)
    여백0~30mm 슬라이더 조절
    페이지 겹침0~50mm — 이전 페이지 끝부분을 다음 페이지에 중복 표시하여 내용 연결 보장
  • 실시간 미리보기: 옵션 변경 시 페이지 분할 결과가 즉시 업데이트됨
  • 비율 유지: 마지막 페이지에 남은 이미지가 적을 경우 용지에 늘리지 않고 원본 비율 그대로 출력
  • 결과 저장: N페이지 PDF 다운로드 클릭
휴대전화 긴 캡처(스크롤 캡처)를 A4 용지에 맞춰 인쇄하고 싶을 때 유용합니다.

5HWP/HWPX ➜ PDF 변환

한글(HWP, HWPX) 문서를 원본 레이아웃 그대로 고속 렌더링하여 PDF로 일괄 변환 및 병합합니다.

  • 지원 포맷: 한컴오피스 .hwp, .hwpx 파일 및 MS Word(.doc, .docx)
  • 드래그 앤 드롭 변환: 한글 문서를 마우스로 드래그하여 목록에 올려놓기만 하면 실시간 변환 엔진이 PDF 파일로 저장합니다.
  • 변환 결과 원축 합치기: 리스트 하단의 변환된 PDF 합치기 & 다운로드 클릭 시 개별 파일들을 한방에 1개의 합본 PDF로 만들어줍니다!
  • 직관적 녹색/적색 표시등 UI:
    • 🟢 변환서버 ON : HWP 탭 진입 시 자동 감지되어 즉시 활성화 및 연동됩니다.
    • 🔴 변환서버 OFF : 타 탭으로 이동 시 불필요한 백그라운드 서버를 조용히 자동 종료시킵니다.
한컴오피스 또는 한글 뷰어 엔진을 연동하므로 표, 도형, 글꼴이 실물 문서 그대로 출력됩니다!

6스마트 서버 & 자동 전환 시스템

사용자의 혼란을 원천 차단하는 맞춤형 제어 및 무음 자동화 기능을 탑재했습니다.

  • 검은 도스창 없는 무음 구동: PDF_Toolkit_실행.bat 또는 탐색기 아이콘 바로가기를 누르면 보기 안 좋은 명령 프롬프트 창 없이 백그라운드에서 상쾌하게 열립니다.
  • Custom Protocol 연계 (pdftoolkit://): 윈도우 레지스트리에 웹앱 연동 프로토콜을 등록하여 탭 전환만으로도 백엔드를 스스로 끄고 켭니다.
  • 5분 무동작 절전 워치독(Watchdog): 300초 동안 아무 상호작용이나 변환 작업이 없으면 자원 보호를 위해 프로세스가 알아서 안전 종료됩니다.
  • 스마트 로컬 접속 감지 (Auto-Link): 사용자가 index.html을 일반 더블클릭(file://)으로 열어도 안내 카드 내의 버튼으로 실행하면, 2초 내로 서버 활성화를 인지하여 즉시 🟢 변환서버 ON 상태로 쾌속 연동됩니다! (로컬 file:// 주소를 그대로 유지하므로, HWP 외의 다른 기능 이용 시 백그라운드 서버가 완전 종료되어도 에러 없이 100% 독립 동작)
압축해서 타 PC로 옮겨 풀더라도 아이콘, 프로토콜 및 바로가기 경로가 스스로 재생성되어 완벽 작동합니다!
