# PDF Toolkit v4.1

**올인원 PDF 및 한글(HWP/HWPX) 문서 통합 솔루션 — HWP 변환 · 병합 · 분할 · 워터마크 · 프린트용 변환**

> 🛡️ 인터넷 연결이나 외부 서버 전송 없이 로컬 PC에서 100% 단독 동작하는 독립형(Standalone) 도구 모음입니다.  
> 검은 터미널 도스창 없는 **무음 숨김 실행 모드(Silent Launch)** 와 **스마트 온·오프 워치독(Watchdog)** 제어 기술이 통합되어 있습니다.

---

## ✨ 주요 기능 및 특징 (manual.html 참조)

### 1. 📑 HWP/HWPX ➜ PDF 일괄 변환 및 합치기 [New in v4]
한컴오피스 한글(`hwp`, `hwpx`) 및 MS Word(`doc`, `docx`) 문서를 원본 레이아웃 및 폰트 깨짐 없이 PDF로 고속 변환합니다.

- **드래그 앤 드롭 실시간 파싱:** 마우스로 복수의 문서를 끌어다 놓기만 하면 즉시 PDF 렌더링 및 개별 파일 저장이 진행됩니다.
- **변환 결과 한방 합치기:** 하단의 `변환된 PDF 합치기 & 다운로드` 버튼 단 한 번의 클릭으로 개별 변환 문서들을 1개의 통합 PDF 문서로 합성합니다.
- **직관적인 ON/OFF 표시등 UI:**
  - 🟢 **변환서버 ON (녹색):** HWP 탭 방문 시 백엔드를 0.5초 내에 자동 인식 및 개방합니다.
  - 🔴 **변환서버 OFF (적색):** 다른 타 탭(병합, 분리 등)으로 이동하면 불필요한 서버 자원을 자동으로 해제하고 조용히 소멸합니다.
- **오른편 COM/레지스트리 예외 해결 툴 탑재:** 한글 엔진 인식 장애나 관리자 레지스트리 이슈 발생 시 원클릭으로 해결할 수 있는 `Fix_HWP_Error.bat`을 기본 제공합니다.

---

### 2. 🤖 스마트 백그라운드 서버 & 자동 감지 시스템 [New in v4]
사용자의 혼란과 불편함을 원천 차단하는 첨단 인터랙션 알고리즘과 포터블 환경을 지원합니다.

- **검은 도스창 없는 무음 구동 (Silent Launch):** `PDF_Toolkit_실행.bat` 이나 톱니바퀴 아이콘을 누르면 거부감이 드는 CLI 명령 창 없이 백그라운드에서 깨끗하고 속도감 있게 열립니다.
- **윈도우 전용 Custom Protocol (`pdftoolkit://`):** 브라우저와 OS 간 맞춤 프로토콜을 레지스트리에 매개하여 웹앱 탭 전환만으로 자율적인 구동 및 종료가 가능합니다.
- **5분(300초) 비활성 시 자동 무응답 타이머 (Watchdog):** 변환 작업이나 조작이 없이 5분(300초)이 경과하면 시스템 자원 및 메모리 회수를 위해 백엔드가 알아서 자동 퇴장합니다.
- **쾌속 스마트 주소 텔레포트 (Auto-Redirect):** 설령 습관적으로 `index.html`을 일반 더블클릭(`file://`)으로 먼저 열었더라도 가이드 안내에 따라 `.bat`을 실행하면, 2초 내로 서버 활성화를 인지하여 실제 백엔드 연동 주소(`http://localhost:8080/`)로 **웹 브라우저 스스로 새로고침 및 순간 이동**합니다!
- **100% 이동식 포터블 보장:** 폴더를 압축해서 타 PC로 옮겨 풀더라도 아이콘, 프로토콜 및 바로가기 파일의 설정이 무제한 자동 복구 및 자립 재생성됩니다.

### 3. 🧩 PDF 병합 (Merge)
여러 PDF 및 이미지 파일들을 순서에 맞게 조합하여 단일 PDF 문서로 합칩니다.

- **지원 포맷:** PDF, JPG, PNG, BMP, GIF, TIFF, WebP
- **다중 선택 및 정렬:** `Ctrl+클릭`, `Shift+클릭` 다중 선택 드래그 및 오름/내림차순(A→Z, Z→A) 자동 정렬 지원
- **페이지 개별 회전 및 삭제:** 문서 내부의 각 페이지 미리보기를 확인하며 편집 및 목차(Bookmark) 수동/자동 생성

---

### 4. ✂️ PDF 분할 (Split)
대용량 PDF 문서를 로드하여 필요한 페이지만 선별 분리 추출합니다.

- **출력 방식 선택:** 
  - 선택한 페이지만 다시 **단일 PDF로 압축 가입 저장**
  - 선택 페이지마다 각각 낱개 문서 또는 이미지(**PNG / JPG 고해상도 1x~3x DPI**)로 분할하여 **ZIP 다운로드**
- **직관적 정렬 번호 부여:** 파일 순서 역전 방지를 위해 4자리 일련번호(예: `_page0001`, `_page0002`...)가 자동 명명됩니다.

---

### 5. 💧 워터마크 삽입 (Watermark)
기업 로고, 인감도장, 보안 기재를 투명하고 세련되게 문서 위에 레이어링합니다.

- **투영 옵션:** 중앙, 상·하·좌·우 가장자리 여백 배치 및 **대각선 바늘 격자 반복(Tile)** 모드 탑재
- **Multiply 블렌딩 알고리즘 적용:** 투명도 및 슬라이드 크기를 조절할 때 원본 PDF 글씨가 완전히 가려지지 않고 깔끔히 스며들도록 설계되었습니다.

---

### 6. 🖨️ 프린트용 변환 (Print Conversion)
모바일 기기 및 브라우저에서 스크롤 캡처한 '매우 긴 형태의 캡처본(Long-Screenshot)'을 A4 폭 크기에 딱 맞춰 다중 페이지로 자동 분할합니다.

- **용지 및 겹침 설정:** A4 / Letter / Legal 지원 및 **0~50mm 페이지 겹침 여유 폭(Overlap)** 지정을 통해 다음 종이로 안심하고 연결해 인쇄할 수 있습니다.
- **실시간 미리보기 및 비율 유지:** 옵션 변경 즉시 실시간 페이지 컷팅 결과를 렌더링합니다.

## 🚀 실행 방법

1. 전체 폴더를 다운로드(ZIP 해제 또는 Git Clone) 받습니다.
2. 아래 2가지 방법 중 하나를 선택하여 간편하게 실행하세요!

### 👉 방법 A: 공식 통합 런처 (권장)
- 폴더 내부에 있는 **`PDF_Toolkit_실행.bat`** 또는 탐색기에 나타난 **`PDF Toolkit v4 (아이콘 실행).lnk`** 를 더블클릭합니다!
- 검은 터미널 창 없이 조용하게 한글(HWP) 및 모든 기능이 활성화된 브라우저 창이 즉시 가동됩니다.

### 👉 방법 B: 일반 웹 브라우저 단독 실행
- 그냥 **`index.html`** 파일을 더블클릭해서 크롬(Chrome)이나 엣지(Edge)로 바로 여셔도 기본 PDF 도구(병합/분할/워터마크)는 즉시 동작합니다!
- *(이 상태에서 HWP 변환 탭 방문 후 화면에 보이는 `실행 파일 바로 열기` 링크 버튼으로 켜주시면, 2초 내에 자동으로 서버 상태를 인식하여 `http://localhost:8080/` 웹앱 환경으로 스마트 자동 전환됩니다)*

```bash
git clone https://github.com/wallofthehell/PDF-Toolkit-3.4.git
```
> 💡 팁: 브라우저에서 `manual.html`을 열고 <kbd>Ctrl</kbd> + <kbd>P</kbd> 를 누르시면 **A4 용지 규격으로 정돈된 공식 인쇄 설명서**를 바로 인쇄하시거나 PDF로 보관하실 수 있습니다!

## 🛠 기술 스택 & 구동 인프라

| 영역 | 활용 기술 및 구성 |
|---|---|
| **프론트엔드 (UI/UX)** | HTML5, CSS3, Vanilla JavaScript, 프리미엄 글래스모피즘(Glassmorphism) 및 다이내믹 펄스 애니메이션 |
| **한글 / Word 엔진** | Python [`pyhwpx`](https://pypi.org/project/pyhwpx/) (한컴오피스 한글 & 뷰어 실시간 렌더러 모듈 자동 연동) |
| **백엔드 제어 시스템** | PowerShell 7+ (`server.ps1`), VBScript 무음 숨김 스크립트, Custom Protocol (`pdftoolkit://`) |
| **PDF 코어 처리** | [pdf-lib](https://pdf-lib.js.org/) (렌더/편집), [PDF.js](https://mozilla.github.io/pdf.js/) (비동기 화면 미리보기 엔진) |
| **파일 파싱 / 압축** | [JSZip](https://stuk.github.io/jszip/), [FileSaver.js](https://github.com/nicktomlin/FileSaver.js), Pillow (.ico 렌더링) |
| **타임아웃 보안** | 300초 무동작 절전 워치독 (Watchdog Asynchronous Polling) |

💡 모든 자바스크립트 및 PDF 조작 도구 모음은 폴더 내 `lib/` 디렉터리에 완전 번들링(Bundled)되어 있어 인터넷 차단 및 산간 폐쇄 환경에서도 **100% 오프라인 완전성**을 자랑합니다.
